# ♔ Шахматы - Chess Game

Классическая игра в шахматы с современным дизайном, созданная на HTML, CSS и JavaScript.

## 🎮 Особенности

- **Полная реализация шахматных правил** - все фигуры ходят по классическим правилам
- **Проверка шахов и матов** - автоматическое определение окончания игры
- **История ходов** - отображение всех сделанных ходов в алгебраической нотации
- **Современный дизайн** - красивый интерфейс с анимациями и эффектами
- **Адаптивная верстка** - игра работает на всех устройствах
- **PWA поддержка** - можно установить как приложение
- **Функция отмены хода** - возможность отменить последний ход
- **Переворот доски** - возможность перевернуть доску для удобства

## 🎯 Функциональность

### Основные возможности:
- ✅ Полная реализация всех шахматных фигур
- ✅ Проверка валидности ходов
- ✅ Обнаружение шахов и матов
- ✅ История ходов в алгебраической нотации
- ✅ Подсветка возможных ходов
- ✅ Отмена последнего хода
- ✅ Переворот доски
- ✅ Новая игра

### Шахматные правила:
- **Пешка**: ходит на одну клетку вперед, первый ход - на две клетки, берет по диагонали
- **Ладья**: ходит по горизонтали и вертикали
- **Конь**: ходит буквой "Г" (2+1 клетки)
- **Слон**: ходит по диагонали
- **Ферзь**: ходит по горизонтали, вертикали и диагонали
- **Король**: ходит на одну клетку в любом направлении
- **Превращение пешки**: автоматическое превращение в ферзя при достижении последней линии

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd chess-game
```

2. Откройте `index.html` в браузере или запустите локальный сервер:
```bash
python -m http.server 8000
# или
npx serve .
```

3. Откройте браузер и перейдите по адресу `http://localhost:8000`

## 📱 PWA возможности

Игра поддерживает установку как Progressive Web App:
- Нажмите кнопку "📱 Установить приложение" в браузере
- Или добавьте в домашний экран через меню браузера

## 🎯 Как играть

1. **Начало игры**: Белые ходят первыми
2. **Выбор фигуры**: Кликните на фигуру своего цвета
3. **Подсветка ходов**: Возможные ходы будут подсвечены
4. **Выполнение хода**: Кликните на подсвеченную клетку
5. **Проверка шахов**: Игра автоматически проверяет шах и мат
6. **История ходов**: Все ходы отображаются справа от доски

### Управление:
- **Новая игра**: Начать новую партию
- **Отменить ход**: Вернуться на один ход назад
- **Перевернуть доску**: Изменить ориентацию доски

## 🏆 Цель игры

Поставить мат королю противника - ситуацию, когда король находится под шахом и не может избежать взятия.
